# 3. The Target Dossiers (Who Did It)

This directory is for the evidence that proves *who* is responsible.

A system does not act; men and women act. This directory will contain a detailed evidence file for every individual state agent—police officer, solicitor, barrister, judge, civil servant—who has played a role in this thirty-year war.

Each dossier will serve as a self-contained indictment, detailing:
*   **Identity:** Name, rank, and role.
*   **Actions:** A chronological list of their specific contributions to the war effort against me.
*   **Evidence:** The specific documents, orders, and communications that prove their involvement.
*   **Charges:** The specific crimes they have committed (e.g., Misconduct in Public Office, Perverting the Course of Justice, perjury).

There is no collective guilt. There is only individual responsibility. This is where that responsibility is assigned and proven. This is the instrument of personal accountability.
